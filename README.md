# QCM de chimie — Prof Hamza Elissaoui

## Contenu
- `index.html` : structure de la page
- `style.css` : design responsive pour ordinateur et mobile
- `script.js` : 100 questions, réponses, explications et calcul du score

## Publication sur GitHub Pages
1. Créez un dépôt GitHub, par exemple `qcm-equilibre-chimique`.
2. Importez les trois fichiers à la racine du dépôt.
3. Allez dans **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez `main` et `/ (root)`, puis enregistrez.
6. GitHub affichera l'adresse de votre site après le déploiement.

Le QCM fonctionne sans serveur ni base de données. Les réponses restent dans la session du navigateur.
